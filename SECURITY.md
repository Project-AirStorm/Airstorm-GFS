# Security Policy

## Supported Versions

Project Airstorm maintains an auto-deployment system that ensures the latest version is always available on our website at https://projectairstorm.com/. Only the most current version is officially supported with security updates.

| Version | Support Status |
| ------- | ------------- |
| Latest  | ✅ Supported |
| Previous Versions | ❌ Unsupported |

## Reporting a Vulnerability

If you discover a security vulnerability, please follow these steps:

1. Navigate to our dedicated security feedback page at https://projectairstorm.com/feedback
2. Submit a detailed ticket describing the vulnerability
3. Our development team will receive immediate notification and begin assessment

### What to Expect

- Our developers will review your submission and take appropriate action
- You will receive updates through the ticket system regarding the status of your report
- For critical vulnerabilities, we aim to provide an initial response within 24 hours
- We appreciate your contribution to making Project Airstorm more secure

### Important Notes

- Please do not disclose the vulnerability publicly until we have addressed it
- Include as much detail as possible in your report to help us reproduce and fix the issue
- If possible, include steps to reproduce, affected versions, and potential impact
